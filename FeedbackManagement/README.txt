EXPERIMENT 7 - FEEDBACK MANAGEMENT MODULE (ASP.NET MVC)

Requirements:
- Visual Studio 2022
- ASP.NET MVC 5 / .NET Framework 4.8 developer pack

How to run:
1. Extract this ZIP file.
2. Open FeedbackManagement.sln in Visual Studio 2022.
3. Allow NuGet packages to restore (right-click solution > Restore NuGet Packages if needed).
4. Build the solution.
5. Press Ctrl+F5 or click IIS Express.
6. The default route opens the feedback form. You can also navigate to /Feedback/Create.

Features:
- Shared MVC layout
- Reusable feedback form partial view
- HTML Helpers
- Server-side Data Annotations validation
- Anti-forgery token
- Success page

Note: This educational sample validates feedback and displays it on the success page. It does not save feedback to a database.
